# practice_03_statistics_ipl

**Тема:** Статистика и качество данных в Python. Исследовательский анализ данных (EDA) и проверка гипотез.

Решение задач с помощью библиотек pandas, seaborn, scipy. Разведочный анализ датасета mpg и базы данных Indian Premier League (IPL), формулировка и проверка статистических гипотез, кодирование категориальных признаков.

## Версия Python

- Python 3.13

## Как запустить программу:

- Скачать файлы репозитория
- Установить зависимости: `pip install -r requirements.txt`
- Скачать файл `database.sqlite` с [Kaggle](https://www.kaggle.com/datasets/harsha547/ipldatabase) и положить в папку проекта
- Открыть и запустить файл `practice_03.ipynb`
